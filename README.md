# Лабораторная работа №3

## Тема

Системы контроля версий Git.

## Участники команды

- Летникова Кира — вариант 12: выбросы парниковых газов в России
- Вакилова Юлия — вариант 4: ВВП и ВНП России

## Используемые технологии

- C#
- Windows Forms
- Git
- GitHub
- GitHub Desktop

## Структура веток

- `main` — главная стабильная ветка проекта.
- `dev` — общая ветка разработки.
- `v12` — ветка разработки варианта 12.
- `v4` — ветка разработки варианта 4.

## Вариант 12

Реализована работа с данными о выбросах парниковых газов в России за последние 15 лет.

Функционал:

- загрузка CSV-файла;
- вывод данных в таблицу;
- построение графиков зависимости выбросов от года;
- вычисление газа, выбросы которого снизились больше всего;
- вычисление газа, выбросы которого снизились меньше всего;
- прогнозирование методом скользящей средней;
- экспорт графика в PNG.

## Вариант 4

Реализована работа с данными о ВВП и ВНП России за последние 15 лет.

Функционал:

- загрузка CSV-файла;
- вывод данных в таблицу;
- построение графиков зависимости ВВП и ВНП от года;
- вычисление максимального процента роста за год;
- вычисление максимального процента падения за год;
- прогнозирование методом скользящей средней;
- экспорт графика в PNG.

## Работа с Git

В ходе выполнения лабораторной работы использовались:

- отдельные ветки для каждого участника;
- осмысленные коммиты;
- Pull Request в ветку `dev`;
- review кода коллег;
- merge веток после проверки.

## Запуск проекта

1. Открыть файл решения `.sln` в Visual Studio.
2. Запустить проект.
3. Выбрать нужную вкладку.
4. Загрузить CSV-файл.
5. Построить график, выполнить прогноз и экспорт при необходимости.
